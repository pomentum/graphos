graphos

A multi-tenant property-graph service: PostgreSQL + Apache AGE behind a typed HTTP API.

Your services send JSON over HTTP. graphos owns the database, writes the SQL against AGE's tables, enforces tenant isolation, and gives you bulk loading, traversal, aggregation, graph algorithms and a web UI. Consumers never get a connection string.

01 · At a glanceWhat graphos is made of

Storage
PostgreSQL 18 with Apache AGE 1.8; each tenant is its own AGE graph
API
Typed HTTP (FastAPI), JSON and NDJSON; the contract at /openapi.json
Access
Users and service accounts, 15-minute tokens, OpenID Connect sign-on, a level per tenant
Algorithms
Louvain (optional extra), PageRank, betweenness, components, degree
Clients
An async, typed Python client; an optional web UI; plain HTTP
Images
ghcr.io/pomentum/graphos-api and graphos-ui, amd64 and arm64
